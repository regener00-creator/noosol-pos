# ลูกค้าและประวัติการซื้อ

เมนูสมุดรายชื่อแยกเป็น **ผู้จำหน่าย → ผู้แทน → ลูกค้า** ข้อมูลผู้ติดต่อเดิมยังอยู่ครบ รายชื่อประเภท “ทั้งคู่” อยู่ได้ทั้งหน้าผู้จำหน่ายและลูกค้าโดยใช้ข้อมูลเดียวกัน ราคาพิเศษยังแก้ไขจากปุ่มเดิม

## วิธีดูประวัติ

1. เปิดเมนู **ลูกค้า** แล้วคลิกชื่อลูกค้า
2. เลือก **รายเดือน** หรือ **รายปี** ระบุปี ค.ศ. / เดือน แล้วกด **แสดงผล**
3. ดูยอดซื้อสุทธิสะสมทั้งหมด ยอดช่วงที่เลือก และระดับปัจจุบัน
4. กด **ดูสินค้า** ในบิลเพื่อดูชื่อสินค้า จำนวน หน่วย และราคาต่อหน่วย ข้อมูลแสดงหน้าละ 10 บิล

นับเฉพาะบิลขายสำเร็จที่ผูกกับรหัสลูกค้า ไม่จับคู่จากชื่อ บิลยกเลิกยังแสดงในประวัติแต่ไม่นับยอด ส่วนบิลพักและเอกสารที่ออกอย่างเดียวไม่ใช่ยอดขาย

## ระดับอัตโนมัติ

ยอดซื้อสุทธิของปีปัจจุบันถึงวันนี้ ÷ จำนวนเดือนตั้งแต่มกราคมถึงเดือนปัจจุบัน

| เฉลี่ยต่อเดือน | ระดับ |
| --- | --- |
| ต่ำกว่า 10,000 บาท | ลูกค้าทั่วไป |
| ตั้งแต่ 10,000 แต่ต่ำกว่า 50,000 บาท | ลูกค้าประจำ |
| ตั้งแต่ 50,000 บาท | ลูกค้าพิเศษ |

ตัวอย่าง: ยอดปีนี้ 90,000 บาท ณ กันยายน → 90,000 ÷ 9 = 10,000 บาท/เดือน → ลูกค้าประจำ

ระดับคำนวณจากยอดจริงและอาจขึ้นหรือลงเมื่อเดือน/ยอดเปลี่ยน เมื่อขึ้นปีใหม่เริ่มคำนวณจากปีใหม่ การเลือกดูประวัติปีเก่าไม่เปลี่ยนระดับปัจจุบัน ระดับไม่เปลี่ยนราคาขายหรือซ้อนโปรโมชั่นอัตโนมัติ

## ความครบถ้วนและสิทธิ์

- เจ้าของร้านเห็นยอดทุกคลัง บัญชีอื่นเห็นเฉพาะบิลตามสิทธิ์คลังของบัญชีนั้น หน้าแสดงข้อความกำกับขอบเขตไว้
- เมนูลูกค้าและผู้จำหน่ายใช้สิทธิ์ “ผู้จำหน่าย / ลูกค้า” เดิมร่วมกัน ไม่เพิ่มสิทธิ์ให้พนักงานโดยอัตโนมัติ
- ยอดสรุปอ่านจากฐานข้อมูลโดยตรง ไม่ใช้รายการขายที่โหลดมาเพียงบางส่วนในเครื่อง
- กด **รีเฟรชยอดซื้อ** เพื่ออ่านข้อมูลใหม่ กรณีโหลดไม่สำเร็จแสดงข้อผิดพลาด ไม่แสดงเป็นยอดศูนย์หรือจัดเป็นลูกค้าทั่วไป
- บิลเก่าที่ไม่ได้ผูกกับรหัสลูกค้าจะไม่ถูกรวมโดยคาดเดาจากชื่อ

## การทดสอบ

- `node tests/customer-purchase-history.test.js`: เกณฑ์ระดับและสิทธิ์
- `node tests/customer-purchase-history-browser.test.js`: เมนู ประวัติ ตัวกรอง แบ่งหน้า ข้อผิดพลาด และการพิมพ์ระหว่างโหลด
- เพิ่ม `--built` หลัง build เพื่อตรวจไฟล์เผยแพร่ที่แยกโหลดเป็นหมวด
- `tests/customer-purchase-history.sql`: ทดสอบคำสั่งฐานข้อมูลที่ติดตั้งจริงผ่านตารางและฟังก์ชันชั่วคราว ทั้งหมดถูก rollback ไม่เขียนข้อมูลทดสอบลงตารางจริง
