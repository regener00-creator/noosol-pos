SAPURI Print 3.0 — คู่มือตั้งค่า VOZY G80 ไร้สาย
สำหรับ Windows 10/11 แบบ 64 บิต (x64)
ปรับปรุงคู่มือ 03-11-2026

เป้าหมาย: ให้ Windows พิมพ์ไปที่ G80 แบบไร้สายได้ก่อน แล้วเชื่อม SAPURI Print
คู่มือนี้อ้างอิงตัวเลือกการเชื่อมต่อของ VOZY และวิธีเพิ่มเครื่องพิมพ์ของ Windows
ชื่อเมนูไดรเวอร์และ Printer Tools อาจต่างตามรุ่นที่ได้รับจากผู้ขาย
ยังไม่ได้ทดสอบกับ G80 เครื่องจริงของคุณ จึงต้องตรวจว่ากระดาษออกในแต่ละจุด

เลือกจุดเริ่มต้น
• คอมนี้พิมพ์ G80 แบบไร้สายจาก Windows ได้แล้ว → ไปหัวข้อ 6
• ตั้งค่าใหม่ผ่าน Bluetooth → หัวข้อ 1, 2, 3, 5, 6, 7
• ตั้งค่าใหม่ผ่าน Wi-Fi หรือ LAN → หัวข้อ 1, 2, 4, 5, 6, 7
• พิมพ์ไม่ได้ → หัวข้อ 8

1. ตรวจว่า G80 ของคุณเชื่อมต่อแบบไหน
----------------------------------
ตรวจฉลากเครื่อง กล่อง ใบสั่งซื้อ หรือสอบถามผู้ขาย รุ่น G80 มีตัวเลือกต่างกัน:
• USB + Bluetooth: ต่อไร้สายตรงจากคอมผ่าน Bluetooth ไม่ต้องใช้เราเตอร์
• USB + Bluetooth + Wi-Fi: เลือกต่อ Bluetooth หรือผ่าน Wi-Fi ของร้าน
• USB + LAN: เครื่องพิมพ์ต่อสาย LAN เข้ากับเราเตอร์ คอมต่อ Wi-Fi ของร้านได้
  แบบนี้คอมไม่ต้องต่อสายกับเครื่องพิมพ์ แต่เครื่องพิมพ์ยังต้องมีสาย LAN
ชื่อ G80 เพียงอย่างเดียวไม่ได้ยืนยันว่ามี Wi-Fi อย่าตั้งค่า Wi-Fi ให้รุ่นที่ไม่มี

2. เตรียมก่อนเริ่ม
-----------------
2.1 เปิดเครื่อง ใส่กระดาษความร้อน 80 มม. ให้ถูกด้าน และปิดฝาให้สนิท
    กด FEED ตรวจว่ากระดาษเลื่อนและไม่มีไฟแจ้งกระดาษหมด/ฝาเปิด
    ถ้าต้องการใบ Self-test หรือ Network configuration ให้ใช้วิธีของคู่มือรุ่นย่อย
    อย่ากดปุ่มค้างแบบสุ่ม เพราะบางเครื่องใช้คำสั่งใกล้เคียงกันเพื่อรีเซ็ตค่า
2.2 ใช้บัญชี Windows ที่จะเปิด SAPURI ขายสินค้าจริง และติดตั้ง Google Chrome
2.3 ดาวน์โหลดไดรเวอร์จาก https://www.vozyprinter.com/pages/downloads
    ในหัวข้อ Drivers เลือก G80, P50 → Windows
    ถ้าจะตั้ง Wi-Fi ให้ดู Printer Tools → T1/T5/T7/T11/G80/P50 → Windows ด้วย
    แตกไฟล์ที่ดาวน์โหลดก่อนเปิดโปรแกรมติดตั้ง/เครื่องมือตั้งค่า
2.4 ติดตั้งไดรเวอร์ตามตัวติดตั้งของผู้ผลิต เลือก G80 หรือชื่อรุ่นที่ผู้ขายระบุ
    ไดรเวอร์อาจตั้งชื่อเครื่องเป็นชื่อทั่วไป ไม่จำเป็นต้องมีคำว่า VOZY
    ถ้าไม่พบ G80 ในรายการ อย่าเลือกเครื่องรุ่นอื่นโดยเดา ให้ตรวจคู่มือในชุดไดรเวอร์
2.5 เตรียมสาย USB หากเครื่องมือตั้งค่า Wi-Fi ของรุ่นนั้นต้องเชื่อม USB ครั้งแรก
    การติดตั้งให้พิมพ์ผ่าน USB ได้อย่างเดียว ยังไม่ถือว่าตั้งค่าไร้สายเสร็จ

3. วิธี Bluetooth
-----------------
3.1 ตรวจว่าคอมมี Bluetooth และเปิดใช้งานแล้ว ถ้าไม่มีต้องมีอะแดปเตอร์ Bluetooth
    วาง G80 ใกล้คอมในช่วงตั้งค่า และหยุดแอปบนมือถือ/คอมอื่นที่กำลังใช้เครื่องนี้
3.2 เปิดโหมดให้ค้นพบหรือจับคู่ตามคู่มือ G80 รุ่นย่อยของคุณ
    Windows 11: Start → Settings → Bluetooth & devices → Add device → Bluetooth
    Windows 10: Start → Settings → Devices → Bluetooth & other devices
                → Add Bluetooth or other device → Bluetooth
3.3 เลือกชื่อที่ตรงกับเครื่องพิมพ์ ยืนยันตัวเครื่องเมื่อมีหลายชื่อใกล้เคียงกัน
    ถ้าถาม PIN ให้ใช้รหัสจากฉลาก ใบทดสอบ คู่มือ หรือผู้ขาย ไม่เดารหัสเริ่มต้น
    รอจน Windows แจ้งว่าจับคู่สำเร็จ
3.4 ตรวจว่ามีเครื่องพิมพ์ใน Printers & scanners แล้วหรือยัง
    Windows 11: Settings → Bluetooth & devices → Printers & scanners
    Windows 10: Settings → Devices → Printers & scanners
    การเห็นอุปกรณ์ในหน้า Bluetooth อย่างเดียวยังไม่ได้แปลว่ามีคิวเครื่องพิมพ์แล้ว
3.5 ถ้าไดรเวอร์รองรับ Bluetooth โดยตรง ให้เลือกเครื่องที่จับคู่ในตัวติดตั้ง
    ถ้าไดรเวอร์ใช้พอร์ตอนุกรม ให้ตรวจพอร์ต COM ที่ Windows สร้างให้:
    • ค้นหา “Bluetooth settings” ใน Start แล้วเปิดตัวเลือก Bluetooth เพิ่มเติม
      ใน Windows บางรุ่นอยู่ใต้ More Bluetooth settings หรือ More Bluetooth options
    • เปิดแท็บ COM Ports ดูพอร์ตขาออก (Outgoing) ที่อ้างถึง G80 เครื่องที่จับคู่
    • จดเลขพอร์ต เช่น COM5 — นี่เป็นเพียงตัวอย่าง ต้องใช้เลขของคอมคุณ
    • ถ้ายังไม่มีพอร์ต และเครื่องรองรับบริการ Serial/SPP ให้กด Add → Outgoing
      เลือกเครื่องพิมพ์และบริการ Serial ที่มีให้ แล้วจดพอร์ตที่ Windows สร้าง
    • ถ้าไม่มีบริการ Serial/SPP ให้ตรวจไดรเวอร์/คู่มือรุ่นย่อยกับผู้ขาย
      อย่าสร้างพอร์ตสุ่มหรือเลือก COM ของอุปกรณ์อื่น
3.6 เลือกพอร์ตนั้นในตัวติดตั้งไดรเวอร์ หรือเปิดเครื่องพิมพ์ที่ติดตั้งแล้ว:
    Printers & scanners → เลือกเครื่อง → Printer properties → Ports
    เลือก COM ขาออกที่ตรงกับ G80 แล้ว Apply
    ถ้าไดรเวอร์มีค่าความเร็วพอร์ต ให้ใช้ค่าที่ผู้ผลิตระบุสำหรับรุ่นนั้น
3.7 ตั้งชื่อเครื่องให้จำง่าย เช่น “G80 Bluetooth” แล้วไปหัวข้อ 5
    ไม่จำเป็นต้องตั้งให้เป็นเครื่องพิมพ์เริ่มต้นของ Windows

4. วิธี Wi-Fi หรือ LAN ผ่านเราเตอร์ของร้าน
-----------------------------------------
4.1 ให้คอมอยู่ในเครือข่ายเดียวกับเครื่องพิมพ์ หลีกเลี่ยงเครือข่าย Guest
    หรือเครือข่ายที่แยกอุปกรณ์ไม่ให้ติดต่อกัน
    ใช้ย่าน Wi-Fi ที่ G80 รุ่นย่อยรองรับ ตรวจจากคู่มือของเครื่อง
4.2 ถ้าเป็นรุ่น LAN: เสียบสาย LAN จากเครื่องพิมพ์เข้าเราเตอร์/สวิตช์ของร้าน
    แล้วข้ามไป 4.5 ส่วนคอมยังใช้ Wi-Fi ได้
4.3 ถ้าเป็นรุ่น Wi-Fi และยังไม่เคยตั้งค่า:
    เปิด Printer Tools สำหรับ G80 จากหัวข้อ 2
    หากคู่มือของเครื่องมือระบุให้ต่อ USB ก่อน ให้ต่อ USB และเลือกเครื่องที่ตรวจพบ
    ใช้คำสั่งอ่านสถานะ/ทดสอบการเชื่อมต่อของเครื่องมือให้ผ่านก่อนเปลี่ยนค่า
4.4 เปิดส่วนตั้งค่าเครือข่ายไร้สายของเครื่องมือ (ชื่อเมนูขึ้นกับเวอร์ชัน)
    เลือกการเชื่อมต่อผ่านเราเตอร์ ถ้ามีให้เลือกระหว่างโหมดเราเตอร์กับโหมดปล่อย Wi-Fi
    ใส่ชื่อ Wi-Fi (SSID) และรหัสผ่านของร้านให้ตรง รวมถึงตัวพิมพ์ใหญ่/เล็ก
    ถ้ามี DHCP ให้เริ่มด้วยรับ IP อัตโนมัติ แล้วบันทึก/ส่งค่าไปยังเครื่องพิมพ์
    รีสตาร์ตเครื่องเฉพาะเมื่อเครื่องมือหรือคู่มือกำหนด
    ถ้าไม่พบเมนู Wi-Fi ให้ตรวจรุ่นเครื่องและเครื่องมือกับผู้ขายก่อนดำเนินการต่อ
    ไม่ใช้คำสั่งรีเซ็ตโรงงานเพื่อทดลองแก้
4.5 หา IP ที่เครื่องพิมพ์ได้รับจากหน้ารายการอุปกรณ์ของเราเตอร์
    หรือใบแสดงสถานะเครือข่าย/เครื่องมือของผู้ผลิต จับคู่กับ MAC address ของเครื่อง
    จด IP จริง ห้ามใช้ IP ตัวอย่างหรือ IP เริ่มต้นจากเครื่องคนอื่น
    ถ้าได้ 0.0.0.0 หรือยังไม่เข้าเครือข่าย ให้กลับไปตรวจสาย/ชื่อ Wi-Fi/รหัสผ่าน
4.6 เพิ่มเครื่องพิมพ์ใน Windows:
    เปิด Printers & scanners → Add device หรือ Add a printer or scanner
    ถ้าไม่พบ ให้เลือก Add manually / The printer that I want isn't listed
    เลือก Add a printer using an IP address or hostname
    เลือก TCP/IP Device ถ้ามีตัวเลือก แล้วใส่ IP ของ G80 จากข้อ 4.5
    เลือกไดรเวอร์ G80 ที่ติดตั้งไว้ หากต้องใช้ Have Disk ให้เลือกไฟล์ไดรเวอร์
    ตามคู่มือผู้ผลิต ไม่เลือกไฟล์ Setup.exe ในช่อง Have Disk
    หากถามชนิดพอร์ตหรือหมายเลขพอร์ต ให้ใช้ค่าที่คู่มือ/เครื่องมือผู้ผลิตระบุ
    ตั้งชื่อเครื่อง เช่น “G80 Wi-Fi” หรือ “G80 LAN” เพื่อแยกจากคิว USB
4.7 แนะนำให้ผู้ดูแลเราเตอร์จอง IP ให้ MAC address ของเครื่องพิมพ์
    เพื่อไม่ให้ IP เปลี่ยนหลังปิดเปิดเราเตอร์ ห้ามกำหนด IP ชนกับอุปกรณ์อื่น
    ถ้า IP เปลี่ยน ต้องแก้ที่ Printer properties → Ports → Configure Port
4.8 เมื่อบันทึกค่าเสร็จและเครื่องเข้าวงเครือข่ายแล้ว ถอด USB ที่ใช้ตั้งค่า
    เพื่อยืนยันว่าขั้นตอนทดสอบต่อไปใช้ Wi-Fi/LAN จริง จากนั้นไปหัวข้อ 5

5. พิมพ์ทดสอบจาก Windows ให้ผ่านก่อน
------------------------------------
5.1 เปิด Printers & scanners → เลือกคิว G80 ที่เป็น Bluetooth/Wi-Fi/LAN
    ถ้ามีคิว USB อยู่ด้วย ให้ตรวจชื่อและพอร์ต อย่าเลือกคิว USB โดยเผลอ
5.2 เปิด Printing preferences เลือกกระดาษสำหรับม้วน 80 มม. ตามไดรเวอร์
    ถ้าไดรเวอร์แสดงพื้นที่พิมพ์ 72 มม. สำหรับม้วน 80 มม. ให้ใช้ตามไดรเวอร์
    ไม่เลือก A4 และไม่สร้างขนาดกระดาษโดยเดาสุ่ม
5.3 เปิด Printer properties → General → Print Test Page
    บางรุ่นของ Windows มีปุ่ม Print test page ในหน้ารายละเอียดเครื่องพิมพ์เลย
5.4 ตรวจว่ากระดาษออกจาก G80 จริง ตัวอักษรอ่านได้ และไม่มีงานค้าง
    ถ้ายังไม่ออก ให้แก้จากหัวข้อ 8 ก่อน เพราะ SAPURI ใช้คิว Windows เดียวกัน
    หน้าทดสอบ Windows ใช้ตรวจการเชื่อมต่อ ยังไม่ใช่ตัวอย่างรูปแบบใบเสร็จ SAPURI

6. ติดตั้งหรืออัปเดต SAPURI Print 3.0
------------------------------------
6.1 ดาวน์โหลดชุด Windows รุ่น 3.0:
    https://github.com/regener00-creator/noosol-pos/releases/download/printing-v3.0/SAPURI-POS-Setup-Windows-v3.0.zip
6.2 คลิกขวาที่ ZIP → Extract All / แตกไฟล์ทั้งหมด แล้วเปิดโฟลเดอร์ที่แตกแล้ว
    ต้องมี SAPURI-POS-Setup.exe และโฟลเดอร์ PrintBridge อยู่ด้วยกัน
    ห้ามเปิด Setup จากภายใน ZIP หรือคัดลอกมาเฉพาะไฟล์ EXE
6.3 เปิด SAPURI-POS-Setup.exe ด้วยบัญชี Windows ที่ใช้ขายสินค้าจริง
    • เคยใช้รุ่น 2.1 หรือมี SAPURI อยู่แล้ว: กด “อัปเดตตัวช่วยพิมพ์”
      ปุ่มนี้ติดตั้งตัวช่วยโดยไม่ต้องตั้งค่าไอคอนหรือโปรไฟล์ใหม่
    • คอมใหม่: เลือกคิว G80 ไร้สาย เลือกใบเสร็จ 80 มม. และกระดาษตามไดรเวอร์
      กด “ตั้งค่าและพิมพ์ทดสอบ” แล้วตรวจใบทดสอบก่อนยืนยัน “กระดาษออกถูกต้อง”
      ถ้าโปรแกรมแจ้งให้ปิดหน้าต่าง SAPURI ก่อนตั้งค่า ให้ปิดเฉพาะหน้าต่าง SAPURI
6.4 ถ้าแจ้งว่าไม่มี Microsoft Edge WebView2 Runtime ให้ติดตั้งจาก Microsoft
    https://developer.microsoft.com/microsoft-edge/webview2/
    สำหรับเครื่อง x64 ใช้ Evergreen Runtime x64 แล้วเปิดตัวช่วยใหม่
6.5 ใช้ตัวติดตั้งจากแหล่งของร้าน ไม่ต้องปิด Defender หรือ SmartScreen
    ไม่ต้องลบโปรไฟล์เก่า ถอนการจับคู่ G80 หรือตั้งค่า Wi-Fi ใหม่หากยังพิมพ์ได้

7. เลือก G80 และพิมพ์จาก SAPURI
-------------------------------
7.1 เปิด SAPURI https://pepo-pharmacy.vercel.app/ ใน Chrome หรือไอคอน SAPURI เดิม
    คอมใหม่ให้เข้าสู่ระบบขณะมีอินเทอร์เน็ตและรอโหลดข้อมูลให้ครบ
7.2 เข้า “ตั้งค่าการพิมพ์” → “เชื่อมต่อตัวช่วยพิมพ์”
    ถ้า Chrome ถาม ให้เปิด SAPURI Print และอนุญาตการเชื่อมต่อในเครื่อง
    รอจนหน้าเว็บแสดงว่าเชื่อมต่อตัวช่วยได้
7.3 ถ้ายังไม่เห็น G80 ให้กด “โหลดเครื่องพิมพ์ใหม่”
    ในกล่อง “ใบเสร็จอย่างย่อ” เลือกคิวไร้สายที่พิมพ์ผ่านในหัวข้อ 5
    กด “บันทึกเครื่องพิมพ์”
    A4 และบาร์โค้ด/ป้ายราคาเป็นคนละกล่อง เลือกตามเครื่องที่ใช้จริง
7.4 กด “ทดลองพิมพ์” ในกล่องใบเสร็จ ตรวจชื่อร้าน ภาษาไทย ราคา และความกว้าง
    การทดสอบนี้ไม่ต้องสร้างบิลขายใหม่ ไม่ต้องขายสินค้าทดลองเพียงเพื่อทดสอบเครื่อง
    แม้ใบทดสอบจากโปรแกรมติดตั้งจะผ่าน ก็ต้องทดสอบจากเว็บอีกครั้ง
    เพราะใบทดสอบในตัวติดตั้งใช้ Chrome ส่วนเว็บที่เชื่อมแล้วใช้ SAPURI Print
7.5 ตรวจว่ากระดาษออกจาก G80 เพียงหนึ่งใบและถูกเครื่อง ก่อนนำไปขายจริง
    หากจะลองพิมพ์บิลเดิม ให้ใช้คำสั่งพิมพ์ใบเสร็จของบิลเดิม โดยไม่สร้างยอดขายซ้ำ
7.6 หลังตั้งค่าเสร็จ ตัวช่วยเปิดพร้อม Windows การเลือกเครื่องเก็บแยกตามคอม
    และบัญชี Windows หากเปลี่ยนคอมหรือบัญชี ต้องติดตั้ง/เชื่อมต่อและเลือกใหม่
    ครั้งต่อไปเพียงเปิด G80 ให้เชื่อมต่อ แล้วเปิด SAPURI

8. แก้ปัญหาตามอาการ
-------------------
• ไม่พบ G80 ใน Bluetooth:
  ตรวจว่าเป็นรุ่น Bluetooth จริง เปิดโหมดจับคู่ตามคู่มือ ย้ายมาใกล้คอม
  และตรวจว่าคอมมี Bluetooth ทำงานอยู่ หยุดการเชื่อมต่อจากแอป/เครื่องอื่นก่อนลอง
• จับคู่แล้ว แต่ไม่พบชื่อใน SAPURI:
  ตรวจว่ามีคิวใน Printers & scanners ติดตั้งไดรเวอร์และผูกพอร์ตให้เสร็จ
  จากนั้นกลับ SAPURI กด “โหลดเครื่องพิมพ์ใหม่” การจับคู่อย่างเดียวไม่พอ
• Bluetooth จับคู่แล้ว แต่พิมพ์ไม่ออก:
  ตรวจพอร์ต COM ขาออกที่ตรงเครื่อง ถ้าเพิ่งจับคู่ใหม่เลข COM อาจเปลี่ยน
  ตรวจ Printer properties → Ports อย่าใช้พอร์ต USB หรือ COM ของอุปกรณ์อื่น
• Wi-Fi/LAN เคยพิมพ์ได้แล้วหยุด:
  ตรวจว่าเครื่องและคอมอยู่เครือข่ายเดียวกัน IP เครื่องยังตรงกับพอร์ต Windows
  และเราเตอร์ไม่ได้แยกอุปกรณ์ หากเปลี่ยนรหัส Wi-Fi ต้องตั้งเครื่องพิมพ์ใหม่ด้วย
• Windows แจ้ง Offline หรือคิวถูกพัก:
  ตรวจไฟ กระดาษ ฝา สัญญาณ และพอร์ต แล้วตรวจ Pause Printing / Use Printer Offline
  ในคิวเครื่องพิมพ์ว่าถูกเปิดไว้หรือไม่
• Windows พิมพ์ได้ แต่ SAPURI ติดต่อ SAPURI Print ไม่ได้:
  เปิดชุดติดตั้ง 3.0 กด “อัปเดตตัวช่วยพิมพ์” แล้วเชื่อมต่อในเว็บใหม่
  ตรวจว่าอนุญาต Chrome เปิด SAPURI Print/เข้าถึงการเชื่อมต่อในเครื่องแล้ว
• ส่งงานแล้วกระดาษไม่ออก:
  เปิดคิว Windows ดูก่อนกดซ้ำ หากมีงานค้างให้แก้การเชื่อมต่อก่อน
  เมื่อต้องยกเลิก ให้ยกเลิกเฉพาะงานของตนที่ตรวจแล้ว ไม่ล้างคิวของผู้อื่น
  ข้อความส่งงานสำเร็จหมายถึงส่งให้ Windows แล้ว ไม่ยืนยันว่ากระดาษออก
• ภาษาไทยเพี้ยน กระดาษล้น หรือตัดผิด:
  ตรวจไดรเวอร์ ขนาดกระดาษ และเลือกคิวที่ถูกต้อง แล้วทดสอบจาก SAPURI ใหม่
  การตัดกระดาษขึ้นกับรุ่น/การตั้งค่าไดรเวอร์ ไม่ใช่เพียงมีการเชื่อมต่อไร้สาย
• อินเทอร์เน็ตขัดข้อง:
  Bluetooth หรือเครือข่ายภายในร้านอาจยังพิมพ์ได้ แต่ต้องเตรียม SAPURI ออฟไลน์ไว้ก่อน
  หาก Wi-Fi/เราเตอร์ของร้านดับ การพิมพ์ผ่านเครือข่ายนั้นจะใช้ไม่ได้
  ถ้าสลับมา USB ต้องมีคิว USB ที่ทดสอบแล้ว และเลือกบันทึกคิวนั้นใน SAPURI

ตรวจครบก่อนใช้งานจริง
--------------------
[ ] ทราบว่าใช้ Bluetooth, Wi-Fi หรือ LAN และเลือกพอร์ตตรงกับการเชื่อมต่อ
[ ] ถอด USB ที่ใช้ตั้งค่าแล้ว ยังพิมพ์หน้าทดสอบจาก Windows ได้
[ ] SAPURI แสดงว่าเชื่อมต่อตัวช่วยแล้ว และบันทึกคิว G80 ในช่องใบเสร็จอย่างย่อ
[ ] ทดลองพิมพ์จาก SAPURI แล้วกระดาษออกจริง ภาษาไทย/ราคา/ความกว้างถูกต้อง
[ ] ปิดเปิดเครื่องพิมพ์และ Windows แล้วลองพิมพ์จาก SAPURI ได้อีกครั้ง
