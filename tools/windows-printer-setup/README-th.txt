SAPURI POS — ชุดตั้งค่าการพิมพ์ Windows 10/11 (64 บิต) รุ่น 3.0

เลือกเครื่องพิมพ์แยกใบเสร็จอย่างย่อ, A4 และบาร์โค้ด/ป้ายราคาในหน้าเว็บ
กดพิมพ์แล้วส่งไปเครื่องที่บันทึกไว้โดยอัตโนมัติ เปลี่ยนเครื่องภายหลังได้
ค่าของเครื่องพิมพ์อยู่ในคอมเครื่องนั้นและบัญชี Windows นั้น ไม่ซิงก์ข้ามคอม

เครื่องที่มีไอคอน SAPURI อยู่แล้ว
1. แตก ZIP ทั้งชุด ห้ามเปิดเฉพาะไฟล์ EXE จากใน ZIP
2. เปิด SAPURI-POS-Setup.exe กด “อัปเดตตัวช่วยพิมพ์”
   ไม่ต้องปิด SAPURI ไม่ต้องตั้งค่าไอคอนหรือเครื่องพิมพ์ใบเสร็จใหม่
3. เปิด SAPURI > ตั้งค่าการพิมพ์ > เชื่อมต่อตัวช่วยพิมพ์
4. ถ้า Chrome ถาม ให้เปิด SAPURI Print และอนุญาตการเชื่อมต่อในเครื่อง
   หากมีช่องให้จำการเปิดตัวช่วยจาก SAPURI สามารถเลือกเพื่อไม่ถามซ้ำ
5. เลือกเครื่องพิมพ์แต่ละประเภท แล้วกด “บันทึกเครื่องพิมพ์” ของประเภทนั้น
6. ตั้งขนาดกระดาษ แล้วทดลองพิมพ์แต่ละประเภท ตรวจผลบนกระดาษจริง
   A4 และบาร์โค้ดไม่ถูกเลือกให้โดยอัตโนมัติ ต้องเลือกเครื่องจริงของร้าน

คอมเครื่องใหม่
1. ติดตั้ง Google Chrome และไดรเวอร์เครื่องพิมพ์ที่จะใช้ใน Windows ก่อน
2. เครื่องต้องมี Microsoft Edge WebView2 Runtime (Windows 11 ส่วนใหญ่มีอยู่แล้ว)
   ถ้าไม่มี ดาวน์โหลดจาก https://developer.microsoft.com/microsoft-edge/webview2
3. เปิด SAPURI-POS-Setup.exe เลือกเครื่องใบเสร็จ 58/80 มม. แล้วตั้งค่าและพิมพ์ทดสอบ
4. เปิด SAPURI และทำตามข้อ 3–6 ด้านบน
5. ปักหมุดไอคอน SAPURI บนเดสก์ท็อปไป Taskbar ได้เหมือนเดิม

การใช้งาน
- ใบเสร็จอย่างย่อส่งไปเครื่องใบเสร็จ; เอกสาร/รายงาน A4 ส่งไปเครื่อง A4
- ป้ายราคา บาร์โค้ดคำสั่ง และฉลากยาส่งไปเครื่องบาร์โค้ด โดยใช้ขนาดตามเอกสารนั้น
- ขนาดป้ายในตั้งค่าการพิมพ์เป็นค่าเริ่มต้น เปลี่ยนเฉพาะงานได้ในหน้าพิมพ์ป้ายราคา
- เปลี่ยนเครื่อง: เพิ่มเครื่องใหม่ใน Windows > โหลดเครื่องพิมพ์ใหม่ > เลือก > บันทึก
- ตัวช่วยเริ่มพร้อม Windows มีไอคอนในถาดระบบ ไม่ต้องเปิดชุดตั้งค่าทุกครั้ง
- ยังพิมพ์ในเครือข่ายร้านได้เมื่ออินเทอร์เน็ตหลุด หาก POS เตรียมออฟไลน์ไว้แล้ว
  ตัวช่วยมีแบบอักษรภาษาไทยในชุด ไม่ต้องโหลดแบบอักษรจากอินเทอร์เน็ตตอนพิมพ์
- อัปเดตเว็บไซต์ตามปกติไม่ต้องลงชุดตั้งค่าใหม่ เว้นแต่แจ้งให้อัปเดตตัวช่วย
- ไม่ใช้ QZ Tray ไม่มีใบรับรองที่ผู้ใช้ต้องต่ออายุ และไม่มีค่ารายเดือนของชุดตั้งค่า

ถ้าติดขัด
- “ติดต่อ SAPURI Print ไม่ได้”: เปิด SAPURI\Printing\App-v3.0\SAPURI-Print.exe
  ภายใต้ %LOCALAPPDATA% หรือเปิดชุดตั้งค่าแล้วกดอัปเดตตัวช่วย จากนั้นเชื่อมต่อใหม่
- ตรวจว่า Chrome อนุญาตการเชื่อมต่อในเครื่องจากเว็บไซต์ SAPURI
- “ไม่พบเครื่องพิมพ์”: เพิ่มไดรเวอร์ใน Windows แล้วโหลดรายชื่อและบันทึกใหม่
- “ออฟไลน์”: เปิดเครื่อง ตรวจ USB/Wi-Fi และคิวพิมพ์ Windows
- หลังส่งงาน หากไม่ทราบผล ให้ตรวจคิวและกระดาษก่อนสั่งใหม่ ระบบไม่ส่งซ้ำเอง
- “ส่งงานแล้ว” หมายถึง Windows รับงาน ยังต้องตรวจว่ากระดาษออกจริง
- เครื่องพิมพ์ PDF/XPS/Fax ไม่รองรับโหมดนี้ เพราะต้องเลือกชื่อไฟล์หรือยืนยันเพิ่ม
- รุ่นนี้เป็นโปรแกรมไม่มีลายเซ็นผู้เผยแพร่ ตรวจแหล่งที่มาและ SHA256.txt
  ไม่ต้องปิด Defender หรือ SmartScreen

ข้อมูลในเครื่อง
- ตัวช่วยและการตั้งค่า: %LOCALAPPDATA%\SAPURI POS\Printing
- printers.json เก็บเครื่องพิมพ์แยกประเภท; paired.json เก็บการจับคู่เบราว์เซอร์
- jobs.json เก็บสถานะงานล่าสุดเพื่อกันส่งซ้ำ ไม่เก็บเนื้อหาบิล
- ตัวช่วยรับคำขอที่ 127.0.0.1:17839 เท่านั้น ตรวจเว็บไซต์ SAPURI และรหัสจับคู่
- เนื้อหาเอกสารถูกส่งภายในเครื่อง ไม่อัปโหลดไปบริการพิมพ์ภายนอก
- ไม่เปลี่ยนเครื่องพิมพ์เริ่มต้น Windows ไม่ล้าง Chrome หรือบิลออฟไลน์

หยุดใช้ตัวช่วย
- คลิกขวาไอคอน SAPURI ในถาดระบบ > ปิดตัวช่วยพิมพ์
- ปิด SAPURI Print ใน Windows Settings > Apps > Startup เพื่อไม่เปิดพร้อม Windows
- อย่าลบโปรไฟล์ SAPURI จนกว่าบิลออฟไลน์จะซิงก์ครบ
