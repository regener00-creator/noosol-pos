SAPURI POS — ชุดตั้งค่าพิมพ์ใบเสร็จอัตโนมัติสำหรับ Windows 10/11 รุ่น 2.1

รุ่น 2.1 แก้หน้าทดสอบพิมพ์หยุดทำงานเมื่อ Chrome ยกเลิกการเชื่อมต่อ และแก้คำอธิบายข้อผิดพลาด

รุ่นนี้เพิ่มโลโก้ SAPURI และรองรับการปักหมุด Taskbar พร้อมคำสั่งพิมพ์อัตโนมัติ
เปิดโปรไฟล์ SAPURI โดยตรง ไม่ต้องเลือกโปรไฟล์ Google Chrome

เริ่มใช้งาน
1. ติดตั้ง Google Chrome และไดรเวอร์ของเครื่องพิมพ์ก่อน
2. เพิ่มเครื่องพิมพ์ใน Windows ผ่าน USB หรือ Wi-Fi/LAN และตรวจว่าพิมพ์ได้
3. แตกไฟล์ ZIP แล้วเปิด SAPURI-POS-Setup.exe ด้วยบัญชี Windows ที่จะขายสินค้า
4. เลือกเครื่องพิมพ์จริง เลือกใบเสร็จ 58 หรือ 80 มม. และขนาดกระดาษของไดรเวอร์
   บางรุ่นแสดงพื้นที่พิมพ์ 72 มม. สำหรับม้วน 80 มม. เป็นค่าปกติของไดรเวอร์นั้น
5. กด “ตั้งค่าและพิมพ์ทดสอบ” โปรแกรมจะตรวจและแสดงผลแต่ละขั้น
6. ตรวจใบทดสอบ แล้วกด “กระดาษออกถูกต้อง” หรือ “ไม่ออก / ไม่ถูกต้อง”
7. กด “เปิด SAPURI POS” เข้าสู่ระบบขณะมีเน็ตและรอข้อมูลโหลดครบครั้งแรก
   ครั้งต่อไปใช้ไอคอน SAPURI POS บนเดสก์ท็อป
8. ปักหมุด: คลิกขวาที่ไอคอน SAPURI POS บนเดสก์ท็อป > Show more options
   > Pin to taskbar (ปักหมุดบนแถบงาน) แล้วเปิดจากโลโก้ SAPURI ได้เลย
   หากเคยปักหมุดรุ่นเก่าแล้วยังเห็นไอคอนผิด ให้ถอนหมุด SAPURI เก่าแล้วปักใหม่
   ไม่ต้องถอนหมุด Google Chrome ที่ใช้ทำงานทั่วไป

อัปเดตจากชุดตั้งค่ารุ่นเก่า
- ปิดหน้าต่าง SAPURI ก่อน แล้วเปิดชุดตั้งค่ารุ่นนี้และเลือกเครื่องพิมพ์เดิม
- ข้อมูลเข้าสู่ระบบและบิลออฟไลน์เดิมยังอยู่ ชุดตั้งค่าไม่ล้างโปรไฟล์
- ซ่อมไอคอนที่ปักหมุดเดิมเฉพาะ SAPURI ที่ใช้โปรไฟล์ของชุดตั้งค่า
- อัปเดตเว็บไซต์ SAPURI ตามปกติไม่ต้องติดตั้งชุดตั้งค่าใหม่
- ไฟล์โลโก้ถาวรอยู่ที่ %USERPROFILE%\SAPURI POS\Assets อย่าลบโฟลเดอร์นี้

ถ้ามีปัญหา
- ดูขั้นตอนสีแดงและคำแนะนำด้านล่าง แก้แล้วกดลองใหม่
- ถ้า SAPURI POS เปิดอยู่ ให้ปิดหน้าหลักและหน้าต่างใบเสร็จก่อนตั้งค่าซ้ำ
  โปรแกรมไม่บังคับปิด Chrome และไม่ล้างบัญชี บิลออฟไลน์ หรือประวัติ
- หากไม่พบกระดาษ ให้ตรวจไดรเวอร์ผู้ผลิตและความกว้าง 58/80 มม.
- ก่อนพิมพ์ทดสอบซ้ำ ตรวจคิว Windows ว่ามีงานค้างหรือไม่
- Windows/Chrome แจ้งจบงานไม่ได้ยืนยันว่ากระดาษออกจริง ต้องตรวจใบพิมพ์ด้วยตนเอง
- กด “บันทึกปัญหา…” เพื่อส่งไฟล์ข้อความให้ผู้ดูแล
- โปรแกรมนี้ยังไม่มีลายเซ็นผู้เผยแพร่ Windows อาจแสดงคำเตือน
  ตรวจแหล่งที่มาและค่า SHA-256 จากผู้ส่งก่อนเปิด ไม่ต้องปิด Defender หรือ SmartScreen

ขอบเขต
- ไม่ติดตั้ง Chrome หรือไดรเวอร์ให้ ไม่เปลี่ยนเครื่องพิมพ์เริ่มต้นของ Windows
- ไม่เก็บหรือคัดลอกรหัสผ่าน Chrome เดิม ต้องเข้าสู่ระบบ SAPURI ครั้งแรกในโปรไฟล์ใหม่
- ไอคอนใช้ Chrome โปรไฟล์แยกใน %LOCALAPPDATA%\SAPURI POS\Chrome
- โหมดนี้ส่งงานพิมพ์ในหน้าต่าง SAPURI ไปยังเครื่องที่เลือกโดยไม่ถามซ้ำ
  งาน A4 หรือบันทึก PDF ให้ใช้ Chrome ปกติ
- ใช้เครื่องพิมพ์ใบเสร็จที่ไดรเวอร์ Windows รองรับกระดาษ 58/80 มม.
  ต้องทดสอบจริงแต่ละรุ่น ไม่รับรองว่ารองรับเครื่องพิมพ์ทุกรุ่น
- ไม่ต้องติดตั้ง QZ Tray ไม่มีค่ารายเดือนของชุดตั้งค่า
- การพิมพ์ทดสอบไม่สร้างรายการขายและไม่ตัดสต๊อก
- อินเทอร์เน็ตขัดข้องยังใช้การพิมพ์ในเครือข่ายร้านได้เมื่อเตรียม POS ออฟไลน์แล้ว
  ถ้า Wi-Fi ร้านหรือเราเตอร์ดับ ต้องใช้ USB ที่ตั้งไว้หรือเชื่อมต่อเครือข่ายใหม่

ถอนการใช้โหมดพิมพ์อัตโนมัติ
หยุดเปิดจากไอคอน SAPURI POS และใช้ Chrome ปกติแทน
อย่าลบโฟลเดอร์โปรไฟล์จนกว่าจะซิงก์บิลออฟไลน์ครบและเก็บข้อมูลที่ต้องใช้แล้ว
