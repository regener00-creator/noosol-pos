SAPURI — ตั้งค่าการพิมพ์ รุ่น 3.0
สำหรับ Windows 10/11 (64 บิต)

ตั้งค่า VOZY G80 ไร้สายครั้งแรก
• เปิดไฟล์ G80-Wireless-Guide-th.txt ที่อยู่ข้างไฟล์นี้
• มีขั้นตอน Bluetooth และ Wi-Fi/LAN ตั้งแต่ติดตั้งไดรเวอร์จนพิมพ์จาก SAPURI
• ถ้า Windows พิมพ์ไร้สายได้อยู่แล้ว ให้ข้ามไปหัวข้อ 6 ในคู่มือนั้น

เริ่มต้น
• แตก ZIP ทั้งชุดก่อนเปิด SAPURI-POS-Setup.exe
• เคยใช้ SAPURI แล้ว: กด “อัปเดตตัวช่วยพิมพ์”
• คอมใหม่: ติดตั้ง Chrome และไดรเวอร์เครื่องพิมพ์ก่อน
  จากนั้นเลือกเครื่องใบเสร็จ 58/80 มม. แล้วกด “ตั้งค่าและพิมพ์ทดสอบ”
  หากโปรแกรมแจ้งว่าไม่มี WebView2 ให้ติดตั้งตามที่แจ้งก่อน

เลือกเครื่องพิมพ์ใน SAPURI
1. เปิด SAPURI > ตั้งค่าการพิมพ์ > “เชื่อมต่อตัวช่วยพิมพ์”
2. ถ้า Chrome ถาม ให้เปิด SAPURI Print และอนุญาตการเชื่อมต่อในเครื่อง
3. เลือกเครื่องพิมพ์ในกล่องที่ต้องการ แล้วกด “บันทึกเครื่องพิมพ์”
   • ใบเสร็จอย่างย่อ → เครื่องพิมพ์ใบเสร็จ
   • เอกสาร A4 → เครื่องพิมพ์ A4
   • บาร์โค้ด / ป้ายราคา → เครื่องพิมพ์ฉลาก
4. กด “ทดลองพิมพ์” และตรวจว่ากระดาษออกถูกต้อง

ถ้าต้องการตั้งค่า A4
1. เลือกและบันทึกเครื่องพิมพ์ในกล่อง “เอกสาร A4” ด้านบน
2. เลื่อนลงไป “กระดาษ A4” เลือก “ตามรูปแบบเอกสาร” และใช้ระยะขอบเริ่มต้นก่อน
3. กด “บันทึก A4” > “ทดลองพิมพ์ A4” > กดพิมพ์ในหน้าตัวอย่าง
ช่อง 58/80 มม. ในโปรแกรมติดตั้งเป็นของใบเสร็จ ไม่ใช่การตั้งค่า A4

ถ้าพิมพ์ไม่ได้
• ติดต่อ SAPURI Print ไม่ได้: กด “อัปเดตตัวช่วยพิมพ์” ในโปรแกรมติดตั้ง แล้วเชื่อมต่อใหม่
• ไม่มีชื่อเครื่อง: ติดตั้งไดรเวอร์ใน Windows แล้วกด “โหลดเครื่องพิมพ์ใหม่”
• เครื่องออฟไลน์: ตรวจว่าเปิดเครื่องและเชื่อมต่อ USB/Wi-Fi แล้ว
• ส่งงานแล้วแต่กระดาษไม่ออก: ตรวจคิวพิมพ์ก่อนกดซ้ำ

จำไว้
• ตั้งค่าครั้งเดียวต่อคอมและบัญชี Windows ตัวช่วยจะเปิดพร้อม Windows
• A4 และฉลากต้องเลือกเครื่องเอง ใช้เครื่องพิมพ์จริง ไม่ใช่ PDF/XPS/Fax
• ดาวน์โหลดชุดติดตั้งจากร้านเท่านั้น ไม่ต้องปิด Defender หรือ SmartScreen
